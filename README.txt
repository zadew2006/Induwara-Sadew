INDUWARA SADEW — PORTFOLIO WEBSITE
==================================

Files:
- index.html
- styles.css
- script.js
- assets/profile.jpg

How to use:
1. Extract the ZIP folder.
2. Double-click index.html to open the portfolio in a browser.
3. For best results, open it with a modern browser such as Chrome, Edge, or Firefox.

The page is fully front-end and requires no build process.

Notes:
- The site content is based on the supplied CV.
- The portrait is the supplied photo.
- Google Fonts are requested by CSS when internet access is available; the site still works with system fallbacks when offline.
