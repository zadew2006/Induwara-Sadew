INDUWARA SADEW — PORTFOLIO WEBSITE

Files
-----
index.html        Main single-page portfolio
styles.css        Premium dark responsive styling
script.js         Animations, interactions, particles, form fallback
assets/logo.svg   Custom IS monogram logo
assets/hero.jpg   Uploaded hero photo
assets/about.png  Uploaded formal photo
assets/Induwara_Sadew_CV.pdf  Uploaded CV

Run locally
-----------
Option 1: Double-click index.html.
Option 2 (recommended): in this folder run:
  python -m http.server 8080
then open http://localhost:8080

Notes
-----
- No formal employers, social URLs or project names were invented.
- The Projects area uses only the two documented project areas from the CV.
- The contact form uses a mailto fallback, so it works without a backend.
- The page includes responsive layout, reduced-motion support, scroll reveal, counters, particles, cursor effects, tilt interactions, filtering, sticky navigation and a CV download.
